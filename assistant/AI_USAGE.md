# AI usage log

How AI was used in this project, honestly.

## Building the code

An AI coding assistant (Instinct) drafted the assistant module under my
direction: `build_db.py`, `query_functions.py`, `router.py`, `app.py`,
`run_eval.py`, the test set, and these docs. I set the requirements: real
public data only, no invented numbers, no accuracy claims until measured, and
an allowlist-only path from questions to data.

What that means in practice:

- Every number the assistant shows comes from executing SQL against the CMS
  and OIG files downloaded by `src/download.py`. Nothing is generated by a
  model.
- The evaluation results in `eval_results.json` are measured by
  `run_eval.py`, not estimated. The file records the timestamp, the data
  snapshot, and the in-sample caveat.
- AI made the work faster and more consistent (boilerplate, tests, docs); it
  did not decide what the data says.

## AI inside the app

The app has two modes:

- **Deterministic (default):** no LLM anywhere in the answer path. A keyword
  router picks an allowlisted function; the function runs fixed SQL.
- **LLM (optional, `OPENAI_API_KEY`):** the model can only call the
  allowlisted read-only functions through tool calling. It never writes SQL
  and never sees the database. Its job is phrasing and function selection;
  the numbers still come from the same executed queries, and the UI shows
  which function produced them.
